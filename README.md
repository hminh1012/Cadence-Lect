## 🔬 Overview

This repository serves as a learning resource for integrated circuit (IC) designers, microelectronics students, and EDA engineers. It covers end-to-end design flows using industry-standard Cadence tools:

- **Analog IC Design Flow**: Schematic capture, Spectre simulation, layout implementation, physical verification (DRC/LVS), and parasitic extraction.
- **Digital Design & Verification Flow**: Verilog/SystemVerilog modeling, simulation with Xcelium, functional verification, and formal verification techniques.

## 📘 Detailed Module Breakdown

### 1. Cadence Analog IC Design Flow v1.0 (Online)
Focuses on fundamental analog circuit design and Cadence Virtuoso tool workflows.
* **Lecture Material (`CAICDF_1_0.secured.lect.pdf`)**: Comprehensive slides on schematic entry, simulation setup, and physical layout.
* **Lab Guide (`CAICDF_1_0.secured.lab.pdf`)**: Hands-on exercises covering Virtuoso Schematic Editor, Spectre Circuit Simulator, Virtuoso Layout Suite, and physical verification.
* **Badge Exam (`Cadence Analog IC Design Flow v1.0 (Badge Exam).docx`)**: Certification badge exam question set with verified solutions.

### 2. Analog IC Design Implementation and Verification
A 16-week academic curriculum for advanced analog IC design.
* **Syllabus & Guidelines**: Excel syllabus detailing weekly learning objectives and grading structure.
* **Weekly Lectures & Labs (`Lectures and Labs/`)**:
  * **Week 1**: Introduction to Analog IC Design & MOSFET Characteristics (`Lab_MOSFETCharacteristics.pdf`, lab databases `.tar.gz`).
  * **Weeks 2–4**: Single-stage & multi-stage amplifiers, current mirrors, and biasing.
  * **Week 5**: Comparators, Stability Analysis, and Common-Mode Feedback (CMFB).
  * **Weeks 6–10**: Layout techniques, matching, guard rings, DRC/LVS.
  * **Weeks 11–16**: Physical verification, parasitic extraction (PEX), post-layout Spectre simulation, and top-level chip assembly.

### 3. Digital Design & Verification Academic Curriculum
A 15-week academic curriculum focused on digital frontend design and verification.
* **Syllabus & Quizzes**: Complete set of weekly quizzes (DOCX & PDF formats with answer keys) for Weeks 1–5, 6–10, and 11–15.
* **Weekly Curriculum (`Week 01` to `Week 15`)**:
  * **Digital IC Design Flow (DICDF)**: Architecture overview, synthesis, and verification overview.
  * **HDL Modeling**: Verilog data types, behavioral modeling, and structure.
  * **Functional Verification**: Simulation setup using Cadence Xcelium, testbench design, and debug workflows.
  * **Formal Verification**: Introduction to formal property verification and verification completeness.
